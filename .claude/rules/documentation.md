# Documentation

- Le comportement et sa documentation changent dans la même demande de fusion.
- Une décision technique entre dans `docs/plan/decisions-agents.md` (identifiant `D-NN` suivant, date, sprints, décision et motif, ce qui a été écarté). Si elle touche le périmètre, elle entre aussi au §12 du CDC.
- Les identifiants RG, D, V, Q et Q-UX sont stables : jamais renumérotés, jamais réutilisés.
- Une question d'expérience utilisateur va dans `docs/plan/questions-ux.md` : la question, l'écran, deux ou trois options avec la recommandation en premier, ce qui en dépend. On applique la recommandation et on continue.
- Les questions du §11 du CDC sont à Léon : un agent n'y répond pas à sa place.
- Une périodicité agronomique porte sa source (`docs/protocole-bibliotheque.md`) ; sans source vérifiable, elle n'entre pas.
- Aucun secret, aucun chemin personnel, aucune donnée réelle dans le dépôt : il est public.
