# Jardin

Un service web de gestion de jardin, pour les particuliers et les professionnels.
Il trace ce qui a été fait sur chaque végétal, et annonce ce qui doit l'être, quand, et ce qu'il en coûte d'attendre.

Le produit est décrit par le [cahier des charges fonctionnel](docs/cahier-des-charges-fonctionnel.md) ;
la façon d'y travailler, par les [consignes des agents](AGENTS.md).
