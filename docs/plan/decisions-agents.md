# Décisions des agents

Chaque décision technique prise en route qui n'est pas dans les chapitres : date,
sprint, décision, ce qui est écarté et pourquoi (README §1, §3). Les décisions
D-01 à D-28 ont été prises en écrivant la partie A du plan ; les suivantes
s'ajoutent à la suite, sans renuméroter.
